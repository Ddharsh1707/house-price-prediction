# House Price Prediction

Predicts house prices from area, bedrooms, age and distance to the city centre, comparing Linear Regression with a Random Forest.

## What you'll learn

- Regression on tabular data
- Interpreting linear model coefficients
- Comparing models with R2 and MAE

## How to run

```bash
git clone https://github.com/Ddharsh1707/house-price-prediction.git
cd house-price-prediction
pip install -r requirements.txt
python main.py
```

No dataset download needed: the data is built into scikit-learn or generated by the script.
